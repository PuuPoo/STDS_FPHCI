# Student Teacher Data System
The Repository contain our groups's finale project for the  
human computer interaction course. our group consist of:  
Agie Winata, Kayla Isabelle, Louis Wibowo, Nizar Ramhadan.  
Our project is some sort of learning management system  
where users can view statiscal data, and send opinion regarding  
both lecturers and students. To ran this file, you can either  
click on the live link or clone the repository and then run the  
index.html.
